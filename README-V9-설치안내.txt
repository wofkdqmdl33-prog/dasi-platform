다시 V9 — 시안 기반 전체 사이트 구현
================================
1. ZIP을 압축 해제한 뒤 GitHub dasi-platform 저장소 루트에 전체 파일 및 assets 폴더 업로드.
2. index.html만 업로드하면 배경 이미지, CSS, JS가 누락됩니다.
3. Cloudflare Pages 자동 배포가 완료되면 index.html / urgent.html / diagnosis.html / schemes.html / dashboard.html / chat.html 확인.

이번 작업:
- 메인: 제공된 시안과 유사한 3단 히어로 레이아웃, 계단/건축 배경 SVG, 상황 입력 카드, 우측 익명 이야기방
- 나이·직업·채무상태·금액·용도·필요시점, 금액 슬라이더 및 연소득/상환회차 고급 입력
- 조건별 공식 기관 경로 우선순위 추천 결과와 안내
- 카테고리 8개, 매거진형 가이드, 카드, 추천 콘텐츠
- 전체 6개 페이지 공통 스타일 보강
- 키보드 ESC 채팅 닫기, 모바일 반응형, 기본 접근성
- 모든 이미지 에셋은 assets 폴더의 자체 제작 SVG이며 타사 저작물 복제 아님.

주의:
- 실제 이용자 채팅과 온라인 인원수는 백엔드 연결 전 표시하지 않습니다.
- 지원정보는 기관 공식 사이트 연결 및 규칙 기반 우선 정렬입니다. 실시간 대출 가능 여부/한도 조회 기능 아님.
- D1/Worker와 실제 API 연결은 별도 후속 작업입니다.
- 검색 및 조회 서버 로그는 현재 연결되지 않았습니다. 개인 금융 입력은 브라우저에서만 처리합니다.
- JS 구문 검사/필수 DOM 검사는 완료, 실제 브라우저 렌더링 자동화는 환경 제약으로 완료되지 않았습니다.
