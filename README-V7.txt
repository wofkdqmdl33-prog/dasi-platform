DASI V7 — 전체 업로드 패키지

1. ZIP 압축을 풀어 파일들을 GitHub 저장소 루트에 업로드합니다.
2. index.html, v7.css, v7.js는 반드시 함께 업로드합니다.
3. 기존 5개 내부 페이지 및 공통 CSS도 포함되어 있습니다.

중요:
- 즉시 탐색은 실제 정책자금 승인 가능성 판정이 아니라 조건별 공식 경로 우선 정렬입니다.
- 휴대전화 소액결제 현금화는 고위험으로 추천하지 않습니다.
- 익명 채팅은 Worker/D1 API 설정 전에는 실시간 송수신이 작동하지 않습니다.
- 현재 사용자 입력은 서버에 저장하지 않습니다. 검색·조회 로그 저장은 별도 동의/고지와 API 구축 후 구현해야 합니다.
- 본 패키지는 UI 개선 및 프런트엔드 탐색 기능으로, 실시간 공고 크롤링이나 심사 결과 연동을 제공하지 않습니다.
