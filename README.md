# 다시 — 1단계: 내 상황 분석 엔진

신한 솔깃에서 영감을 얻은 기존 블루 에디션 UI를 유지하며, 회원가입 없는 5단계 상황 분석 흐름을 구현한 정적 웹 프로토타입입니다.

## 실행

`python -m http.server 8000` 실행 후 http://localhost:8000 에 접속합니다. 별도 npm 설치나 API 키가 필요하지 않습니다.

## 구성

- `index.html`: 기존 블루 메인 화면, 진단 버튼으로 분석 화면 진입
- `diagnosis.html`: 반응형 5단계 상황 입력 및 결과
- `diagnosis.js`: 입력 상태, 단계 이동, 결과 렌더링
- `engine.js`: 순수 규칙 기반 공식 기관 탐색 엔진
- `test-engine.js`: Node.js 기본 assert로 실행하는 테스트

## 개인정보·한계

- 분석 입력은 브라우저 메모리에서만 처리합니다. 서버 전송, localStorage 저장, 사용자 프로필 수집은 없습니다.
- 인쇄/PDF 저장 기능은 사용자가 선택한 경우에만 브라우저 인쇄 기능을 사용합니다.
- 현재 결과는 특정 금융상품이나 정부 지원사업의 자격 판정이 아닙니다. 공식 기관 탐색 경로만 제공합니다.
- 메인의 채팅은 실제 실시간 채팅이 아닌 체험 UI입니다.
- 메인 방문자 수 124,000명+일 30명은 실제 방문 통계가 아닌 시연용 수치이며 실제 광고 영업에 사용하면 안 됩니다.
- 실제 서비스 전 개인정보처리방침, 약관, 광고 고지, 접근성, 제도별 출처/검증일, 법률 검토, 실제 분석 및 채팅 백엔드가 필요합니다.

## 테스트

`node test-engine.js`
