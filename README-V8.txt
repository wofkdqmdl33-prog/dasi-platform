다시 V8 프리미엄 통합 웹사이트

적용:
1. ZIP 압축 해제
2. 저장소 wofkdqmdl33-prog/dasi-platform 의 루트에 HTML/CSS/JS 파일 모두 업로드 및 기존 파일 교체
3. Cloudflare Pages 자동 배포 확인
4. 메인에서 나이/직업/채무 상태 선택, 금액 입력 후 '가능한 경로 찾기' 확인

포함:
- index.html 프리미엄 신규 메인 (상황별 탐색, 우측 상단 익명 채팅, 카테고리, 편집형 가이드)
- premium.css, premium.js 신규 메인 스타일 및 상호작용
- premium-inner.css, premium-inner.js 나머지 5개 페이지 프리미엄 통일
- 기존 V7 엔진, 제도 DB, 정밀 진단, 로드맵, 채팅 클라이언트
- backend-d1: Cloudflare Worker/D1 코드 예시 (미배포)

중요:
- 채팅은 Cloudflare Worker API 연결 전 실제 메시지 송수신 불가. 메인 채팅 미리보기는 명확히 '예시' 표시.
- 지원 경로는 규칙 기반 탐색 안내. 실시간 자격 판정, 대출 승인, 즉시 지급을 보장하지 않음.
- 데이터 수집/방문자 추적 및 24시간 메시지 삭제는 Worker/D1 연결 후 별도 검증 필요.
- 개인 금융정보 서버 저장은 동의·고지·보안 설계 전에는 구현하지 않음.
- 신한 SOL깃의 디자인을 그대로 복제하지 않고, 사용자 제공 레퍼런스 이미지의 레이아웃 감성을 반영.
- 브라우저 실화면 렌더링 테스트는 환경 제한으로 미완료. JS 문법 검사는 완료.
