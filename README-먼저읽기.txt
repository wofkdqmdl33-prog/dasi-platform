다시 V6 — 전체 페이지 디자인 통합 패키지
======================================
배포: ZIP 압축 해제 후, 모든 HTML/JS/CSS 파일을 GitHub 저장소 루트에 교체/추가 업로드.
중요: ZIP 파일 자체를 GitHub에 업로드하는 것으로는 웹사이트가 교체되지 않습니다.

이번 버전:
- 메인 / 긴급자금 / 진단 / 지원제도 / 회복 로드맵 / 익명 이야기방 6개 페이지
- 전 페이지 동일한 헤더, 우측 상단 익명 이야기방, 모바일 메뉴
- 통일된 타이포그래피, 색상, 버튼, 입력창, 카드, 여백
- 내부 페이지별 에디토리얼 헤더와 상태 태그
- 기존 분석 및 채팅 JS 기능 파일 보존
- 최신 진단 브리지 호환성 수정 포함
- Cloudflare D1 서버 예제는 backend-d1 폴더에 보관

추가 파일: dasi-design.css, dasi-shell.js, dasi-pages.js (반드시 함께 업로드)
주의: site-config.js의 DASI_API_BASE는 아직 비어있습니다.
채팅/자동 갱신/방문자 서버 통계는 Workers 및 D1 연결 전에는 작동하지 않습니다.
이 패키지는 페이지 디자인/프런트엔드 통합본이며 실제 자격 승인 판정이나
공식 제도 데이터의 자동 최신 검증 기능을 제공하지 않습니다.
개인 금융정보는 사용자의 명시적 동의와 적법한 처리 체계 없이 서버에 저장하지 마세요.
